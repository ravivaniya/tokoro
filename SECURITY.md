# Security Policy

## Supported Versions

Currently, only the latest main branch of tokoro is supported with security updates.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in tokoro, please report it via email to hello@ravivaniya.com 

Please include:
- A description of the vulnerability.
- Steps to reproduce the vulnerability.
- Any potential impact.

We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress. If you have not received a reply within 48 hours, please reach out again.
